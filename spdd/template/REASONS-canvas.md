# Plantilla de canvas REASONS

Usa una copia de esta plantilla para cada historia o funcionalidad que requiera
un plan propio. Mantén enlaces a requisitos, análisis y decisiones. Si algo no
está decidido, anótalo como pendiente; no completes el comportamiento por
suposición.

| Revisado por | |

## R — Requirements (requisitos)

Problema, alcance y criterios de aceptación observables. Incluye la fuente de
cada requisito.

## E — Entities (entidades)

Entidades, relaciones y datos que entran, salen o se persisten.

## A — Approach (enfoque)

Estrategia elegida, alternativas relevantes y decisiones que la justifican.

## S — Structure (estructura)

Archivos, módulos, dependencias y servicios externos implicados.

## O — Operations (operaciones)

Pasos de implementación en orden. Para cada paso, indica archivos afectados,
resultado esperado y cómo se verificará.

1. **Pendiente:** …

## N — Norms (normas)

Convenciones compartidas: idioma, nombres, configuración, logs, errores y
formato de cambios.

## S — Safeguards (salvaguardas)

Invariantes, límites y comportamientos prohibidos; incluye riesgos y qué no se
debe afirmar sin evidencia.
